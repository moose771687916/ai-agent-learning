货币政策基础知识

一、什么是货币政策？
货币政策是中央银行（中国人民银行）通过调节货币供应量和利率，来影响经济的政策。

简单说：央行觉得经济太热了，就收紧货币；经济太冷了，就放松货币。

二、货币政策工具

1. 利率（LPR）
- LPR = 贷款市场报价利率
- LPR降 = 借钱便宜了 = 刺激经济
- LPR升 = 借钱贵了 = 抑制经济

2. 存款准备金率（降准/升准）
- 银行要把一部分钱存在央行，不能全部贷出去
- 降准 = 银行可以多贷钱 = 放松货币
- 升准 = 银行要少贷钱 = 收紧货币

3. 公开市场操作（MLF/逆回购）
- 央行直接给银行放钱或者收钱
- 放钱 = 放松货币
- 收钱 = 收紧货币

三、宽松货币政策（放水）

什么时候用？经济差的时候。
怎么做？降息、降准、放钱。
对股市的影响？
1. 钱变多了，一部分流进股市 → 股市涨
2. 存钱利息低了，大家愿意炒股 → 股市涨
3. 企业借钱便宜了，愿意投资 → 经济好 → 股市涨

四、紧缩货币政策（收水）

什么时候用？经济太热、通胀太高的时候。
怎么做？加息、升准、收钱。
对股市的影响？
1. 钱变少了，从股市流出去 → 股市跌
2. 存钱利息高了，大家不愿意炒股 → 股市跌
3. 企业借钱贵了，不愿意投资 → 经济差 → 股市跌

五、货币政策对不同板块的影响

1. 宽松货币（降息降准）利好哪些板块？
- 房地产（借钱买房便宜了）
- 券商（股市涨，券商赚钱）
- 科技成长股（未来值钱的股票）
- 有色金属（钱多了，大宗商品涨）

2. 紧缩货币（加息升准）利好哪些板块？
- 银行（存钱利息高了，银行赚钱）
- 公用事业（水电煤气，稳定）
- 高股息股票（分红高的股票）

六、什么时候货币政策会变？
1. CPI太高 → 收紧货币
2. GDP太低 → 放松货币
3. 股市太跌 → 放松货币（托市）
4. 楼市太热 → 收紧货币

七、怎么关注货币政策？
1. 央行官网（www.pbc.gov.cn）
2. 每月LPR公布（20号左右）
3. 每季度货币政策报告
4. 央行行长讲话
