# 手写RAG全过程：从余弦相似度到Milvus三件套

> 为什么手写？因为面试官问"RAG怎么做的"时，能讲出每一个环节，才证明真的懂。框架（LangChain）只是封装，底层的检索逻辑是面试重点。

## 一、RAG是什么？（一句话）

**RAG（Retrieval-Augmented Generation，检索增强生成）= 先检索资料，再让LLM根据资料回答。**

为什么要RAG？
- LLM知识有截止日期（不知道新东西）
- LLM会编造（幻觉！）
- 企业数据是私有的（不在LLM训练集里）

RAG = 给LLM"开卷考试"！（先查书！再答题！不编了！）

## 二、完整6环节（亲手实现！）

```
① 读文档   ← 打开txt/PDF/Word，读全文
② 切块     ← 把长文切成小块（200字/块）
③ 向量化   ← embedding模型：文字 → 1024维向量
④ 存储     ← 向量+原文存进向量数据库
⑤ 检索     ← 用户问题 → 向量 → 找最像的3块
⑥ 生成     ← 把检索到的资料给LLM → 回答
```

### 环节②：为什么要切块？

因为LLM上下文有限（一次只能看几千字），而且整篇文档塞进去：
- 太长了 → LLM看不完
- 太杂了 → LLM抓不住重点（相关性被稀释）

切块后：检索只取"最相关的3块"！精准！

### 环节③：向量化是什么？

- 文字 → 数字！（embedding模型：如BGE-M3！1024维向量！）
- "相似的意思" → "相近的数字"！（"北京天气"和"北京气候"向量很近！）
- 这就是语义搜索的基础！（传统数据库做不到！）

### 环节⑤："最像"怎么算？（余弦相似度！）

```python
def cos(a, b):
    # 夹角越小越像！0°=1（100%像）90°=0（无关）180°=-1（相反）
    return sum(x*y for x, y in zip(a, b)) / (
        (sum(x*x for x in a) ** 0.5) * (sum(y*y for y in b) ** 0.5) + 1e-9)
```

关键坑：**查询的向量必须和库里的向量用同一个embedding模型！**（换模型=重新建库！）

### 环节⑥：生成（提示词是关键！）

```python
messages = [
    {"role": "system", "content": "只根据资料回答！资料里没有就说不知道！"},
    {"role": "user", "content": f"资料：\n{context}\n\n问题：{question}"}
]
```

这个提示词 = 幻觉三解法之一！（约束LLM别编！）

## 三、向量数据库怎么选？（FAISS vs Milvus）

| | FAISS | Milvus |
|--|-------|--------|
| 定位 | 本地库！（程序内嵌！） | 独立数据库！（服务器！） |
| 数据量 | 百万级以内 | 亿级（分布式！） |
| 部署 | 一行代码！ | Docker三件套！（etcd+MinIO+standalone！） |
| 适合 | 学习/小项目/车载端侧 | 企业生产 |

**车载场景**：FAISS存车机本地！（离线秒答！22条知识=90KB！）

## 四、真Milvus部署（Docker三件套！）

```
milvus-etcd        ← 记账的！（元数据！谁存了啥！）
milvus-minio       ← 仓库！（对象存储！向量文件！）
milvus-standalone  ← 前台！（查询服务！）
```

- etcd = 记账本！（记录"数据在哪"！）
- MinIO = 仓库！（真正存文件！）
- Milvus = 前台！（响应查询！）

**关键坑**：Server版插入数据后必须 `flush`！（提交落盘！）不flush检索不到！

## 五、进阶技巧（面试加分！）

- **重排序（Rerank）**：先粗检20条！再用重排序模型精排取3条！（更准！）
- **混合搜索（Hybrid）**：向量检索 + 关键词检索 合并！（向量找"意思"！关键词找"名字"！互补！）
- **多查询（Multi-Query）**：一个问题扩写成5个问法！分别检索再合并！（召回更多！）

## 六、实测结果（全部跑通！）

- 手写6环节RAG：问"CPI太高对股市有什么影响？" → 检索到CPI原文 → 智谱答"通胀严重，央行可能加息，股市跌" ✅
- 车载手册RAG（FAISS持久化）：问"黄灯亮了什么意思？" → 检索仪表盘知识 → "黄色警示灯代表车辆有需要关注的问题" ✅
- 多模态RAG（图生文）：问"蓝色的方形" → 命中蓝方块图（相似度0.908）✅

## 总结

> RAG = 开卷考试！核心是"检索准不准"！手写一遍6环节，你就真正懂了：切块为什么、向量是什么、余弦怎么算、为什么必须flush、怎么防幻觉。框架会封装，但面试问的是底层。
